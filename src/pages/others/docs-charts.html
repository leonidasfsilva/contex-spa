Charts

Every chart in Apex Dashboard is a single declarative element: <apex-chart>. It wraps ApexCharts, reads its configuration from data-* attributes plus one inline JSON child, and respects the OKLCh design tokens so it looks right in both light and dark modes â€” no JavaScript wiring required per chart.

Overview

<apex-chart> is a light-DOM custom element defined in src/components/apex-chart.js. On connect it parses its child <script type="application/json">, builds the ApexCharts options from the attributes, and renders into a <div> it appends to itself. It also subscribes to theme changes and re-renders with the new palette automatically.

Because each instance carries its own data, charts are completely independent â€” copy any example, change the JSON, and it works anywhere. Shared axis / grid / tooltip styling comes from baseChartOptions() in src/lib/charts.js.

Inline JSON Config

The data goes in a single child <script type="application/json">. It is parsed once on connect â€” invalid JSON silently aborts the render, so keep it valid. 

// Cartesian (area / line / bar / radar)
{
  "series": [{ "name": "Revenue", "data": [12, 18, 15, 22, 28, 30] }],
  "categories": ["Jan", "Feb", "Mar", "Apr", "May", "Jun"]
}

// Circular (donut / pie / radialBar)
{
  "series": [42, 35, 15, 8],
  "labels": ["Mobile", "Desktop", "Tablet", "Other"]
}

Chart Color Palette

Five chart colors are defined as OKLCh CSS custom properties in src/styles/main.css, with separate values for light and dark modes: --chart-1 through --chart-5. Pass them to data-colors by token name (without the leading dashes). The component resolves each token to its computed value at render time and re-resolves it on theme change, which keeps colors correct when the user toggles dark mode. 

<apex-chart data-type="bar" data-colors="chart-1,chart-3,chart-5" ...>

Sparklines

Small area / line charts render as clean sparklines (no axes, grid or tooltip). Opt in explicitly with data-sparkline="true", or implicitly by giving a short data-height of 64 or less. This is how the stat cards embed their trend lines. 

<apex-chart data-type="area" data-colors="chart-1" data-height="48" data-sparkline="true">
  <script type="application/json">
    { "series": [{ "name": "Trend", "data": [12,18,15,22,28,30] }] }
  </script>
</apex-chart>

Adding a Chart to a Page

Wrap the chart in an .apex-card with a header for a finished panel â€” the same pattern used throughout analytics.html and charts.html: 

<div class="apex-card">
  <div class="flex flex-col space-y-1.5 p-6 pb-2">
    <h3 class="text-base font-semibold">Page Views Over Time</h3>
    <p class="text-xs text-muted-foreground">Monthly visitor traffic trends</p>
  </div>
  <div class="p-6 pt-4">
    <apex-chart data-type="line" data-colors="chart-1" data-height="300" data-y-format="number">
      <script type="application/json">
        { "series": [{ "name": "Visitors", "data": [245,312,278,389,421,385] }],
          "categories": ["Jan","Feb","Mar","Apr","May","Jun"] }
      </script>
    </apex-chart>
  </div>
</div>

Note: <apex-chart> is one of the few custom elements that is display: block (not display: contents), because ApexCharts renders into a real box. For circular charts, constrain the size with a sized wrapper (e.g. class="h-52 w-52") as charts.html does for the radial gauge.
